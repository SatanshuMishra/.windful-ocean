# 0715. The brief repair is gated by a code-block lint that first carried the defect it checked for

## Context

Repairing the remaining briefs worst-first needed an instrument, otherwise the repair is prose graded by prose. The first lint scanned whole brief bodies and flagged every brief whose repair paragraph quoted the defect it had just removed, and read a vertical bar inside a query expression as a shell pipe. Both are the same failure the repair exists to remove: a pattern matcher answering a slightly different question than the one asked. It was corrected to parse only fenced code blocks, to require a settlement poll in the same block as a checks read, and to accept the word mutate rather than only mutation, which a fixture unit had used.

## Options

- Repair the briefs by reading them in priority order and rewriting what looks wrong
- Build a lint over the briefs, repair what it names, and record what it provably cannot see
- Defer the repair until a fresh session can audit every brief substantively

## Outcome

The lint runs over twenty-four briefs and twenty-eight code blocks and now reports zero failures, with one exemption carrying a written reason for the import unit, which changes no behaviour and correctly has no red-on-parent test. Repaired against demonstrated defects: the publication unit, whose three checks were counts printed beside expectation comments and whose criteria were all negative, so a licence naming a wrong repository with the reservation gutted satisfied every one, and whose sixth criterion rested on a gate the same unit authored; the two units that certified the suite by comparing count fields a pattern never extracted; the four host-lane units that read a checks command's exit code while checks were still queued; and the lane unit that concluded no billing occurred from a log it never proved it fetched. The boundary is recorded rather than blurred: twelve briefs carry code blocks with no halt-on-empty language, and the lint cannot decide whether any of their checks can pass over an empty set. That is a substantive per-brief read, it is the class the four auditors found roughly sixty of, and it has not been done for those twelve.
