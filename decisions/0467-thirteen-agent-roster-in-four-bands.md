# 0467. Replace all 56 agents with 13 in four bands, with the dispatch tool held only by the Opus leads

## Context

Telemetry over 46 days showed 95.6% of 15,301 runs flowing through 8 of 56 agents, with performance-engineer at 1 run and verification-strategist at 0. Zero of 15 global agents held the Agent tool, so every task needing delegation escaped to general-purpose. Prose boundaries between agents were contradicted by identical tool grants. External evidence bounds CONCURRENT team size at 3-5 (inverted-U, peak n=3-4) but says nothing about catalogue size.

## Options

- Keep a large roster of narrow specialists (the pathfinder pattern, 33 agents) - rejected: telemetry shows narrow agents go unused and routing degrades
- Collapse to 5-6 broad agents - rejected: loses the five categories of work that already have no owner, and re-creates context dilution
- 13 agents in four bands, tool grants enforcing the boundaries - chosen
- Keep 15 and only fix the tool grants - rejected: leaves nine ornaments and no delegation capability

## Outcome

Adopt 13 agents in four bands: Leads (delivery-lead, architect, investigator, researcher) on opus/high effort holding the Agent tool; Makers (implementer, test-engineer, platform-engineer, release-engineer) on sonnet/medium with NO dispatch tool; Verifiers (code-reviewer, security-reviewer, conformance-auditor on opus, verifier on sonnet/low); Scribe (technical-writer). Colour encodes band: purple, blue, green, cyan - no warm hues. The load-bearing structural choice is that only Leads hold the Agent tool, which makes the Opus-thinks/Sonnet-executes rule a permission rather than a request: a Sonnet agent cannot start work nobody planned. Three new roles cover previously unowned work: conformance-auditor (artifact-vs-artifact and invariants), release-engineer (git/PR/merge), verifier (runs the check, emits the receipt). Roster size 13 is a catalogue figure; concurrent fan-out stays bounded at 3-5. Every agent must declare StructuredOutput in tools: or the new engine's dispatchable-agent-schema-capable gate fails.
