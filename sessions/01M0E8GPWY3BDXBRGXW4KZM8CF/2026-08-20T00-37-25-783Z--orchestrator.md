## What the specification settles

The body becomes five sections in a fixed order: what changed, why, risk, verification, links. Nothing follows the last section. No opening summary sentence is added, because the title already carries the one-sentence description and adding a field would work against the subtraction bias the owner set.

Attribution is removed by deletion rather than by a guard. The origin and provenance flags go, and the tool's existing unknown-flag check rejects them for nothing. A census test over globbed source files makes the removal permanent by failing if any banned wording returns.

The trailer sentence currently doubles as the reuse-detection key, so deleting it needed a replacement. The replacement checks the tool's own heading skeleton with four exact string comparisons. It names no tool and no agent, and a caller cannot forge it because the value sanitiser already refuses any value beginning with a hash.

Sentence structure is enforced only as typography: a prose value starts with a capital letter and ends with a full stop, question mark or exclamation mark. Grammar, readability scoring, jargon detection and identifier spotting are declared permanently unenforceable and written into the specification as non-goals, so a later session cannot reopen them as unfinished work. Five externally-owned continuous-integration tokens are exempt, because those must sit at the start of a line for the enforcer to read them.

The size warning and the internal unit identifier list are deleted from the body. The supersedes link survives in readable form.

## What the owner decided when asked

Prefix-stripping inside the sentence adapter was dropped, because its guard was a heuristic that could truncate a legitimate sentence containing a colon. The risk section stays optional, because a required field invites filler the tool cannot detect. The internal dependency line is deleted outright, confirmed as having no external consumer.

## What was not done

Nothing was implemented. Seven follow-ups are filed rather than built, and all four previously identified gaps were held out of scope.

## Known stall point for the next session

The census bans the word provenance across the whole engine library. If an unrelated use exists there, the acceptance criterion cannot be met as written. The specification says to stop and raise it rather than add an exception, because an exception turns a closed census into an allowlist.
